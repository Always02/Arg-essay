# 知行 · 时政与申论（GitHub Pages 零 API 版）

一个纯静态、移动端适配的个人学习网站。不需要构建工具、服务器或 API。

## 当前功能
- 时政阅读：手动收录新闻/政策、主题分类、搜索、收藏、原文链接、个人笔记。
- 申论题库：试卷与单题两种视图；创建试卷；创建/编辑题目；录入材料、踩分点、分值、评分说明和参考答案。
- 作答工作台：浏览器本地草稿、提交历史、查看/隐藏参考答案。
- 无 API 批改流程：一键复制包含题目、材料、踩分点、参考答案和用户答案的 ChatGPT 批改请求；在 ChatGPT 中批改后，可将分数、踩分点核对、反馈录入网站。
- 数据导入导出：整站 JSON 备份、新闻导出、申论题库与作答导出、导入 JSON。
- 响应式布局，适配桌面和手机。

## 在 GitHub Pages 发布
1. 在 GitHub 新建一个 repository，例如 `zhixing-study`。
2. 上传 `index.html` 和 `README.md` 到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 里选择 **Deploy from a branch**。
5. Branch 选择 `main`，文件夹选择 `/(root)`，保存。
6. 等待 GitHub Pages 发布，页面会显示网址。

## 重要限制
- 网站数据保存在当前浏览器的 localStorage，不会跨设备同步。定期在“资料管理”中导出 JSON 备份。
- 浏览器清除站点数据、切换浏览器或使用无痕模式，都可能导致数据无法继续访问。
- 当前新闻模块是手动录入，不会自动抓取新闻。
- 网站不直接调用 AI。复制批改请求后，需要手动粘贴到 ChatGPT；网站也不会自动读取 ChatGPT 回复。
- 不要把私人作答数据或备份 JSON 上传到公开 GitHub 仓库。公开仓库中的代码文件会被他人查看。
- 这是初始可用版本，建议先用示例数据熟悉流程，再导入自己的资料并定期备份。

## 导入题库 JSON
独立题库最小示例：
```json
{
  "papers": [
    {"id": "p1", "title": "2025年某省申论", "year": "2025", "region": "某省"}
  ],
  "questions": [
    {
      "id": "q1",
      "title": "概括题",
      "paperId": "p1",
      "type": "归纳概括",
      "prompt": "请概括……",
      "materials": "材料……",
      "maxScore": 20,
      "points": [
        {"score": 4, "text": "要点一"},
        {"score": 3, "text": "要点二"}
      ],
      "reference": "参考答案……",
      "rubric": "评分说明……"
    }
  ]
}
```
踩分点可以在编辑器中按每行 `分值 | 要点内容` 输入。
